Static Toolkit

One place for your daily tools.

This GitHub Pages home screen links to the three standalone tools in this repository. Everything here is static HTML, so it deploys cleanly with no build step.

GitHub Pages serves index.html automatically, so this page becomes the public entry point for the repository site.
